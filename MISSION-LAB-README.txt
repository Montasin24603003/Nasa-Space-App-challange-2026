MISSION LAB UPDATE

The home page remains visually unchanged.
A new dedicated page was added:

/mission-lab

It contains two modes:
1. 3D Terrain — the existing interactive Mars explorer plus the 7 supplied regional GLB models.
2. Simulator — the mission survival simulator in the same workspace, with a link to the full Sol-by-Sol page.

A new "Mission Lab" item was added to the desktop and mobile navigation.

Run:
npm install
npm run dev

Then open the URL shown by Vite and choose Mission Lab from the navigation.
